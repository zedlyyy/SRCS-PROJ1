PROJECT 1 - SRSC 2024

## Overview

Java implementation of a secure datagram transport layer built on UDP sockets. The project explores protecting network messages using cryptographic mechanisms for confidentiality and integrity, including support for multicast communication.


## Technologies and scope

- **Java and UDP sockets:** Datagram-based communication.
- **Cryptographic message protection:** Confidentiality and integrity of exchanged data.
- **Multicast:** Communication support beyond one-to-one exchanges.

This is an academic prototype, not a production-hardened secure transport protocol.
